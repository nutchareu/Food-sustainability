## คำแนะนำ
- ใช้รูปที่มีสิทธิ์ใช้งาน เช่น Unsplash, Pexels, Pixabay หรือรูปที่ถ่ายเอง และใส่เครดิตตามที่แหล่งภาพกำหนด
- ย่อไฟล์ให้ไม่เกิน ~300 KB ต่อรูป เพื่อให้เว็บโหลดเร็ว
- ถ้าใช้ไฟล์ .webp หรือ .png ให้แก้นามสกุลในแท็ก `<img src="images/...">` ของ index.html ให้ตรงกัน
- แก้ข้อความ `alt` ให้อธิบายรูปที่ใช้จริง (เพื่อการเข้าถึงและ SEO)
